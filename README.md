Overview

Our project focuses on enhancing robotic perception by developing a deep learning model capable of real-time object detection within its environment. Beyond traditional detection, the model also generates rich image and object-level embeddings, or tokens, which can be leveraged by subsequent models to support autonomous driving tasks. By combining accurate object recognition with the creation of structured, informative representations, our system enables a robot to not only understand its surroundings but also provide meaningful data for higher-level decision-making processes — all optimized for real-time performance critical to autonomous navigation.
